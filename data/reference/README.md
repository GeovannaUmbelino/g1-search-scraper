# Amostra de referência

Este diretório deve conter uma amostra **independente e manual**, transcrita da interface
visível do G1 no mesmo instante da coleta. O arquivo `manual_sample.json` começa vazio de
propósito: preencher automaticamente com a saída do scraper produziria uma avaliação
circular e metodologicamente inválida.

Selecione os primeiros resultados (cinco nesta entrega), registre `title`, `url`, `published_at`,
`result_page` e `observed_at`, e faça uma segunda conferência visual. Depois execute o
coletor novamente para gerar as métricas.
